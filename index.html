Original and Enhanced Artifact

The selected artifact is a CS 360 Android Weight Tracking App. The original application supports account creation and login, dated weight records, editing and deletion, goal-weight tracking, SQLite persistence, and optional SMS notifications. The enhanced version preserves that core purpose while improving three layers of the system.

Software Design & Engineering

Added a repository boundary, centralized validation, refactored Activities, stronger input rules, and meaningful unit tests.

Algorithms & Data Structures

Added chronological sorting, inclusive date filtering, progress calculations, recent-trend analysis, and algorithm-focused tests.

Databases

Added a data-preserving schema migration, ISO date storage, stronger constraints, a composite index, and database-level date-range queries.
