# CS 499 Computer Science Capstone ePortfolio

This repository presents my CS 499 capstone ePortfolio and documents the progression of my CS 360 Weight Tracking App across three enhancement categories:

- Software design and engineering
- Algorithms and data structures
- Databases

The portfolio includes the professional self-assessment, original and enhanced technical artifacts, enhancement narratives, and a section for the recorded code review.

The GitHub Pages site is designed to make the material easy to navigate for both technical and nontechnical audiences.
